# Участие в разработке

Для ошибки или идеи откройте Issue. Укажите версию macOS, процессор и Balbis.
При обрывах полезен журнал из «Настройки → Диагностика → Причины переподключений».

Изменения нативного кода находятся в macos/Sources, маршрутизатор — в macos/router.
Проверки запускаются командой `./macos/test.sh`, сборка — `./macos/build.sh universal`.
Проверка жизненного цикла доступна через `./macos/test-runtime.sh`.
Проверяйте изменения на macOS 13 и отмечайте, на каких процессорах они запускались.

Сохраняйте авторство и лицензии сторонних компонентов.

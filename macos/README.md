# Balbis для macOS 13+ · 0.8.1

Самостоятельное приложение для macOS Ventura и новее: AppKit/Swift, tpws для обхода DPI,
зарубежный HTTP CONNECT выход Opera и маршрутизатор доменов Balbis.
Universal-приложение содержит Intel и Apple Silicon. Python, Go, Homebrew,
драйверы и отдельный VPN-клиент для запуска не нужны.

## Новое в 0.8.1

Мягкие скруглённые края прокрутки с эффектом матового стекла. Выключение YouTube
теперь учитывает его поддомены из основного списка. В «Мои сайты» нельзя сохранить
однословное правило вроде `com`; такие старые записи не применяются при чтении.

## Новое в 0.8.0

В «Исключения» добавляются домены без ссылок и путей. Они и их поддомены идут
напрямую с приоритетом над зарубежным списком, «Мои сайты» и режимом «Все сайты».
Изменения применяются при следующем подключении. Исключения работают в системных
режимах и в маршрутизаторе ручного режима при включённом зарубежном подключении.
Если ручной клиент использует только локальный обход DPI, правила обхода нужно
настроить в самом клиенте.

«Основной список сайтов» позволяет редактировать весь встроенный базовый список.
Укажите по одному домену в строке без URL и путей. Некорректные строки отклоняются.
Можно добавлять и удалять домены, сохранить пустой список или нажать
«Восстановить встроенный», чтобы вернуть исходные значения. Со следующего
подключения сохранённый список заменяет основу «Избранного» и встроенного
зарубежного маршрута. Фильтр YouTube продолжает действовать, «Мои сайты» добавляются
отдельно, а исключения сохраняют наивысший приоритет.

«Уведомлять о сбоях» включается по желанию. Разрешение macOS запрашивается только
при явном включении. После нескольких неудачных попыток подключения или восстановления появляется одно
уведомление за текущий обрыв с действиями «Повторить» и «Открыть настройки».
Попытки продолжаются с паузами 5, 15, 30 и затем 60 секунд. Успешное восстановление
или ручное отключение сбрасывает эпизод, повторное уведомление возможно при новом обрыве.

Внутри существующего раздела «Диагностика» кнопка «Подготовить отчёт» показывает
предпросмотр текста, не открывая отдельное окно.
Сначала проверьте содержимое, затем нажмите «Сохранить отчёт…» и выберите файл .txt
в системном диалоге. Автоматической отправки нет. В отчёт входят версия приложения,
macOS, архитектура, признаки состояния подключения, наличие файла службы и до 100
последних событий из хвоста журнала не более 16 КБ. Допускаются только известные
структурированные события. IP-адреса, аккаунты, домашние пути, списки доменов,
токены, исходные запросы и необработанные журналы движка не включаются.

## Автозапуск и автоподключение

В настройках доступны два независимых переключателя:
- «Запускать вместе с macOS» — открывает Balbis в фоне после входа в учётную запись.
- «Подключаться автоматически» — подключается с сохранёнными параметрами при открытии Balbis, дождавшись сети.

Для подключения после входа в macOS включите оба. Приложение должно быть
установлено в «Программы». Если macOS требует подтверждения, нажмите
«Открыть настройки macOS» и разрешите автозапуск.

Ожидание сети можно отменить кнопкой «Отменить». Автоподключение делает одну
попытку за запуск. При ошибке причина показывается в панели. Если другой VPN
уже управляет прокси, Balbis предлагает завершить его. Установку помощника
нужно один раз закончить вручную. Незавершённый сеанс Balbis восстанавливается
перед автоматическим подключением, когда помощник готов.

## Разрешение macOS

При первом системном подключении Balbis устанавливает службу подключения.
macOS запросит пароль администратора один раз. Дальнейшие включения и
отключения используют установленную службу. При её переустановке или смене
пользователя разрешение может потребоваться повторно.

Служба запускается через launchd от root и обслуживает одну разрешённую
учётную запись. Она принимает только проверку готовности, включение PAC
на loopback-адрес Balbis и восстановление захваченных ею параметров.
Другие программы этой же учётной записи также могут обращаться к этому
ограниченному интерфейсу. Произвольные команды служба не выполняет.
Журнал восстановления хранится в защищённой системной папке.

Удалить службу можно в «Настройки → Диагностика → Удалить службу подключения».
Сначала отключите Balbis и восстановите незавершённое подключение, если оно есть.
Удаление требует разрешения администратора. Старые сеансы, созданные до
обновления, завершаются прежним способом и могут один раз запросить пароль.

## Панель Balbis

Balbis работает в строке меню. Нажмите на щит, чтобы открыть панель,
и нажмите вне панели или Escape, чтобы закрыть её. Закрытие панели
сохраняет подключение. Значок в Dock не показывается.

В главном экране выберите «Избранное» или «Все сайты» и нажмите
«Подключить». Настройки открываются кнопкой справа вверху. Страна,
дополнительные способы подключения и диагностика находятся там же.
Для полного выхода откройте настройки и нажмите кнопку питания внизу.

Оформление вдохновлено Liquid Glass. На macOS 13 используются системное
размытие и полупрозрачные поверхности, без новых API macOS 26/27.

## Запуск

Распакуйте ZIP, закройте старую Balbis и перенесите новую Balbis.app в «Программы».
Сборка имеет ad-hoc подпись, без Apple Developer ID и нотариализации. Если macOS
блокирует скачанную копию, разрешите именно эту проверенную вами сборку через
«Системные настройки → Конфиденциальность и безопасность». Не отключайте Gatekeeper.

По умолчанию включён «Зарубежный IP для списка». При подключении Balbis выбирает
выход в Европе, проверяет передачу HTTPS, страну выхода и ответ OpenAI API
без ключа/аккаунта. Если европейский узел не подходит, режим «Авто» пробует США.
Можно выбрать регион вручную. Проверка может занять около минуты.
Страна и результат проверки отображаются в окне. Ответ 401 означает доступность
API без авторизации; браузерный доступ, вход и отсутствие CAPTCHA не гарантируются.

## Клиент ChatGPT / Codex

Клиент можно открывать обычным способом, когда его встроенный runtime настроен
использовать системный прокси (`features.respect_system_proxy = true`). После
изменения этой настройки требуется один полный перезапуск клиента.
Сама Balbis настройки клиента автоматически не меняет.

Подключите Balbis в режиме «Домены Balbis» или «Все сайты» и оставьте её работающей.
Окно Balbis можно закрыть: приложение остаётся в строке меню. Отдельная кнопка
запуска ChatGPT удалена в 0.2.2; параметры окружения клиента не подменяются.

Локальный порт маршрутизатора принимает SOCKS5 и HTTP CONNECT (для HTTPS/WSS).
TLS не расшифровывается, заголовки/данные приложения не журналируются.
После установления туннеля нет короткого idle timeout: длительные SSE/WebSocket
передаются как поток байтов. Plain HTTP через этот порт не поддерживается.

Документация о системном прокси native runtime и его ограничениях:
https://learn.chatgpt.com/docs/enterprise/managed-configuration#use-the-system-proxy-for-native-client-requests
Идентификация/проверка авторизованной сессии зависит от конкретной версии клиента;
до пользовательского перезапуска её автоматически не проверяем, чтобы не оборвать чат.

## Какие сайты идут через туннель

В routing/foreign.txt находится список, предоставленный пользователем 2026-11-04:
нейросети, YouTube, Meta, X, Discord и другие перечисленные сервисы.
Имена действуют вместе со всеми поддоменами, без захвата похожих имён.
Исправлена опечатка sndcdn.comå → sndcdn.com. Дополнительные домены не добавлялись.

Для Google в туннель идут только перечисленные Google AI-имена.
Поиск, почта, карты и остальной Google не направляются в зарубежный выход.
«YouTube через туннель» можно выключить: тогда YouTube остаётся на уже работавшем
обходе DPI. Отключение «Зарубежный IP для списка» возвращает поведение 0.1.1 —
только DPI без смены IP.

Туннель работает поверх HTTPS-прокси Opera/SurfEasy; это общий сторонний сервис,
без гарантии скорости, постоянного адреса или приёма IP конкретной нейросетью.
Balbis передаёт TLS без расшифровки, не устанавливает корневые сертификаты.
Если зарубежный узел отказывает, домены списка получают ошибку, а не скрытый
переход на прямое соединение с российским IP. При завершении одного из движков
Balbis останавливает сеанс. Повторное подключение запускает новый выбор узла.

## Локальный режим и существующий VPN

По умолчанию выбран «Локальный SOCKS5 · без изменения сети».
Он не меняет системный прокси, VPN, DNS, маршруты или hosts. Ваш работающий VPN
оставьте включённым. После подключения укажите показанный SOCKS5-адрес в нужном
приложении. Один адрес сам разделяет домены между зарубежным выходом и tpws.
Порт выбирается на каждый сеанс. Нужен SOCKS5 с удалённым разрешением имён
(socks5h / proxy DNS): без исходного имени нельзя выбрать доменное правило.
При включённом туннеле запросы SOCKS к IP-литералам отклоняются.

Пример для Terminal, заменив ПОРТ показанным числом:

    curl --socks5-hostname 127.0.0.1:ПОРТ https://api.openai.com/v1/models

Скопированный PAC-адрес можно отдельно задать в приложении с поддержкой PAC.
Системная сеть при этом остаётся под управлением текущего VPN. Если VPN реализован
только собственным прокси, отдельная настройка SOCKS в приложении заменит его
прокси для этого приложения; совместимость зависит от VPN-клиента.

## Системный PAC (по желанию)

«Домены Balbis» направляет выбранные домены через единый маршрутизатор.
Домены зарубежного списка имеют приоритет над общими исключениями.
Остальные домены из исходных списков Balbis идут через tpws. «Все сайты» отправляет
через tpws также остальные публичные домены. Исключения, локальные имена,
.local и IP-литералы идут напрямую в PAC, без обращения к локальному DNS из PAC.
Режим PAC не перехватывает приложения, игнорирующие системный прокси.

Выберите службу, например Wi-Fi, затем режим и «Подключить». macOS запросит
пароль администратора после успешной проверки движков. Изменяется только PAC
выбранной службы. При смене Wi-Fi на Ethernet отключитесь и выберите новую службу.
Balbis отказывается менять службу с уже включённым HTTP/HTTPS/SOCKS-прокси или
автообнаружением, чтобы не перезаписать конфигурацию работающего VPN.

Прежние PAC URL/состояние сохраняются до изменения. При отключении или завершении
они восстанавливаются, если текущий URL всё ещё принадлежит сеансу Balbis.
Более новые настройки пользователя/VPN не перезаписываются. Если прежде PAC
отсутствовал, Balbis выключает его; неактивный URL может остаться в поле настроек,
так как networksetup не принимает пустой URL. Это исправлено в версии 0.1.1.
При отмене разрешения на восстановление сеанс остаётся запущенным для повторной попытки.

При аварии главного процесса отдельный supervisor останавливает дочерние процессы
и пытается вернуть PAC. Восстановление может запросить пароль администратора.
Если оно отклонено или завершены оба процесса, при следующем запуске нажмите
«Восстановить прокси». Журнал:

    ~/Library/Application Support/Balbis macOS/proxy-session.json

Если приложение удалено/повреждено, отключите только автоматическую настройку
прокси Balbis у соответствующей службы и верните прежний URL из журнала, если он был.
Не меняйте прокси своего VPN.

## Ограничения

- Только TCP и клиенты SOCKS/PAC. UDP/QUIC, игры и голосовые звонки не покрыты.
- Геоблокировка может зависеть также от аккаунта, оплаты, cookies и репутации IP.
- Нет WARP/MASQUE/AWG/VLESS/Tor, Telegram relay, маршрутизации по процессам,
  обучения стратегий, автообновления и автозапуска Windows-версии.
- Автовосстановления туннеля без переподключения нет. EU → США пробуются при старте.
- Локальные слушатели только на 127.0.0.1, доступны процессам текущего компьютера
  без аутентификации. Проксирование к локальным адресам ограничено движками.
- Границы TCP-записей могут объединяться macOS; проверено разделение TLS records,
  успех обхода конкретного DPI зависит от провайдера.

Журнал: ~/Library/Application Support/Balbis macOS/engine.log. Новый сеанс его заменяет.
Отладочный вывод запросов и учётные данные Opera не пишутся в журнал.
Закрытие окна оставляет Balbis в строке меню; используйте «Отключить» или «Завершить».

## Сборка и проверки

Требуются Command Line Tools со Swift 5.8+, macOS SDK 13+, Go 1.24+ для
stdlib-маршрутизатора. При отсутствии Go скрипт скачает SHA-pinned Go 1.26.10
локально в macos/build/tools, без глобальной установки. Opera берётся из
SHA-pinned upstream release v1.31.0 (см. tunnel/README.md), tpws собирается
из включённых исходников. После загрузки зависимостей сборка возможна без сети.

    ./macos/build.sh                   # Universal Intel + Apple Silicon
    ./macos/build.sh x86_64            # Только Intel
    ./macos/build.sh arm64             # Только Apple Silicon
    ./macos/test.sh                    # Изолированные проверки PAC/DPI
    ./macos/test-runtime.sh            # Lifecycle готового .app
    ./macos/test-runtime.sh --live-foreign  # Реальный localhost-туннель и страна

Go-тесты в router/ покрывают передачу байтов, правила доменов, удалённый DNS,
запрет возврата foreign-трафика в DPI, ограничение CONNECT-заголовков.
Проверки не меняют VPN, системные прокси, DNS или маршруты.
Intel проверяется на macOS 13.7.8; Apple Silicon — кросс-компиляцией,
требуется исполнение на устройстве. Живая установка/откат системного PAC
с действующим VPN при разработке не выполняется. Визуальная проверка окна
ранее была недоступна из-за сбоя сервиса управления интерфейсом.

## Лицензии

Самостоятельный нативный код Balbis распространяется по MIT, © 2026 Strokin.
Начальные списки доменов сформированы из предоставленного пользователем перечня.
tpws, epoll-shim и Opera-proxy сохраняют собственные лицензии и авторство.
Тексты лицензий включены в приложение. Закреплённые исходники и контрольные
суммы находятся в engine/ и tunnel/. Balbis не связана с Opera/SurfEasy.

Сборка использует deployment target macOS 13.0 и содержит x86_64 и arm64.
Запуск на macOS 27 и физическом Mac с Apple Silicon пока не проверен.
Перед первым запуском Balbis полностью завершите предыдущую версию. Данные
предыдущей установки переносятся при первом запуске.

## Проверка и восстановление

В настройках «Проверить подключение» проверяет маршрут через локальные порты
Balbis, показывает страну зарубежного выхода и доступность OpenAI без входа
в аккаунт. Доступность API не подтверждает авторизованный сеанс клиента.

«Восстанавливать при обрыве» включает проверки после сна, изменений сети
и раз в минуту. При недоступном маршруте Balbis переподключается, повторяя
неудачные попытки с паузами 5, 15, 30 и затем 60 секунд. Ручное отключение
или кнопка отмены прекращают попытки до следующего ручного подключения.

Страну можно менять при активном подключении. При неудаче Balbis пытается
восстановить прежний маршрут. Если оба маршрута недоступны, действует
выбранная настройка восстановления.

В «Мои сайты» добавляются домены без ссылок и путей. Они и их поддомены
используют зарубежный выход при его включении. Изменения применяются
при следующем подключении.

## Проверки стабильности

Фоновая проверка маршрута выполняется отдельно от подключения и не меняет
его статус. Восстановление запускается после трёх последовательных транспортных
ошибок, с проверкой двух независимых адресов. Ответы сайтов 403, 429 и 5xx
не считаются обрывом транспорта.

В диагностике «Причины переподключений» открывает ограниченный по размеру
журнал событий. Он записывает причины перезапуска и коды завершения движков.
Токены, cookies и содержимое пользовательских запросов в него не записываются.
